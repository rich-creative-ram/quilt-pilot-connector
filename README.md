# QuiltFlow Connector

Downloads for the QuiltFlow Connector, the Windows app that sends your MQBM records to QuiltFlow.

- **Most PCs with MQBM:** download `QuiltFlowConnector-x86.zip`.
- Use `QuiltFlowConnector-x64.zip` only if the app asks for it.

Unzip, then run `QuiltFlowConnector.exe`. If Windows says "Windows protected your PC", choose **More info → Run anyway**.
