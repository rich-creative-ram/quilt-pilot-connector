# Quilt Pilot Connector

Downloads for the Quilt Pilot Connector, the Windows app that sends your MQBM records to Quilt Pilot.

- **Most PCs with MQBM:** download `QuiltPilotConnector-x86.zip`.
- Use `QuiltPilotConnector-x64.zip` only if the app asks for it.

Unzip, then run `QuiltPilotConnector.exe`. If Windows says "Windows protected your PC", choose **More info → Run anyway**.
